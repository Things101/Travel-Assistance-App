# Travel Companion App 🌍

An interactive travel planning web app that combines data from the **Weather API**, **Google Maps API**, and **Travel Advisor API** to help users discover top attractions, restaurants, and hotels in any given area.

## ✨ Features

- 🔍 **Search Locations** using Google Maps
- 🗺️ **Map-based Interface**: Results update dynamically as you move the map
- 🏨 **Place Categories**: Filter by **Attractions**, **Restaurants**, and **Hotels**
- ⭐ **Rating Filter**: Narrow down results by user rating
- 🌦️ **Weather Information**: Current weather conditions shown for the selected area
- 📍 **Location Cards on Map**: Each place is displayed as a clickable card overlay
- ⚡ **Dynamic Content**: Automatically updates based on map boundaries

## 🛠️ Built With

- **JavaScript**
- **React**
- **Material-UI** for UI components and styling
- **Axios** for API requests
- **HTML** & **CSS**
